# 🔮 Predict Future Model

## 🧠 Giới thiệu
Dự án **Predict Future Model** xây dựng mô hình **LSTM (Long Short-Term Memory)** để dự đoán **giá cổ phiếu trong tương lai** dựa trên dữ liệu lịch sử và các chỉ báo kỹ thuật.

Mục tiêu:
- Huấn luyện mô hình Deep Learning dựa trên chuỗi thời gian (Time Series).
- Dự đoán xu hướng giá **Close** trong 30 ngày kế tiếp.
- Trực quan hóa, đánh giá mô hình, và xuất dự báo ra kết quả trực quan.
